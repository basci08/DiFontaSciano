Formati di interscambio

Il formato CSV

Il CSV, ovvero Comma-Separated Values, è un formato di file testuale utilizzato per organizzare e scambiare dati in forma tabellare, ovvero suddivisi in righe e colonne. È uno dei formati più diffusi grazie alla sua semplicità e facilità di utilizzo.

Un file CSV è composto da:

  • Righe: rappresentano i singoli record, ovvero le informazioni relative a un elemento;
  • Colonne: rappresentano i campi, cioè le caratteristiche degli elementi;
  • Delimitatori: separano i diversi valori presenti in una riga, solitamente tramite virgole o punti e virgola.

Caratteristiche e peculiarità

Una delle principali caratteristiche del CSV è la sua struttura semplice. I dati vengono salvati come testo e possono essere aperti con programmi come Microsoft Excel, LibreOffice Calc oppure con un semplice editor di testo.

Il CSV occupa generalmente poco spazio ed è particolarmente adatto allo scambio di grandi quantità di dati organizzati in tabelle. Tuttavia, non permette di rappresentare direttamente strutture complesse o relazioni tra diversi elementi.

Esempio di codice CSV

Nome;Cognome;Età
Mario;Rossi;18
Luca;Bianchi;20
Anna;Verdi;19

In questo esempio la prima riga contiene i nomi delle colonne, mentre le righe successive contengono i dati delle persone. Il punto e virgola viene utilizzato come delimitatore.

Il formato XML

XML, ovvero eXtensible Markup Language, è un linguaggio di marcatura utilizzato per memorizzare e scambiare dati in modo strutturato. Permette di organizzare le informazioni utilizzando dei tag, cioè delle etichette che identificano il significato dei dati.

Caratteristiche e peculiarità

XML permette di creare tag personalizzati, rendendo possibile l'organizzazione dei dati in strutture gerarchiche. Ogni elemento può contenere altri elementi, creando una struttura ad albero.

È un formato molto leggibile sia dalle persone sia dai computer e viene utilizzato soprattutto nello scambio di informazioni tra applicazioni differenti. Rispetto al CSV è più dettagliato, ma generalmente occupa più spazio.

Esempio di codice XML



    
        Mario
        Rossi
        18
    
    
        Luca
        Bianchi
        20

In questo esempio il tag principale è <studenti>, che contiene più elementi <studente>. Ogni studente possiede tre informazioni: nome, cognome ed età.

Il formato JSON

JSON, ovvero JavaScript Object Notation, è un formato testuale utilizzato per rappresentare e scambiare dati. È molto diffuso nello sviluppo di applicazioni web e nella comunicazione tra client e server.

Caratteristiche e peculiarità

JSON organizza le informazioni attraverso coppie chiave-valore. Le chiavi identificano i dati, mentre i valori rappresentano le informazioni associate.

Utilizza principalmente due strutture:

  • Oggetti: sono racchiusi tra parentesi graffe { } e contengono coppie chiave-valore;
  • Array: sono racchiusi tra parentesi quadre [ ] e permettono di contenere più valori.

JSON è leggero, semplice da leggere e facilmente interpretato da molti linguaggi di programmazione. Rispetto a XML utilizza una sintassi più compatta e generalmente richiede meno spazio.

Esempio di codice JSON

{
    "studenti": [
        {
            "nome": "Mario",
            "cognome": "Rossi",
            "eta": 18
        },
        {
            "nome": "Luca",
            "cognome": "Bianchi",
            "eta": 20
        }
    ]
}

In questo esempio abbiamo un oggetto chiamato studenti che contiene un array con due studenti. Ogni studente è rappresentato da un oggetto con tre coppie chiave-valore.
